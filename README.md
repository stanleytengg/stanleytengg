## 🚀 Featured Projects

### Harmonic Scanner — Algorithmic Trading Research Platform
`Python` `PostgreSQL` `SQLAlchemy` `FastAPI` `GCP`

- Ingests 12+ market, macro, and on-chain APIs and 3 WebSocket streams into a 19-table Postgres time-series schema
- Idempotent upserts and exponential-backoff reconnects, running on a 1GB GCP VM
- Serves 19 FastAPI endpoints plus a backtesting harness (Sharpe, expectancy), covered by 458 tests

### OnlyHyper — Hyperliquid Data Pipeline & Analytics
`TypeScript` `PostgreSQL` `Supabase` `Prisma` `GitHub Actions` `Next.js`

- Integrates three financial APIs into a 12-model, 15-index Supabase Postgres schema via Prisma
- Fill-level deduplication, historical backfills, and a daily GitHub Actions job
- Powers a Next.js dashboard that reconstructs a buyback ledger past the exchange's ~40-day fill-history limit

### PPG Paint Popularity Prediction
`R` `caret` `XGBoost`

- Benchmarked 11 tuned classifiers under repeated 5-fold cross-validation; XGBoost reached 85.9% pooled out-of-fold accuracy
- Feature-importance and subgroup error analysis identified hue as the dominant predictor and midtone-neutral paints as the weakest segment (64.7%)
